# Indian Domestic Flight Price Analysis (Excel Dashboard)

An interactive Excel dashboard analysing 300,153 domestic flight listings across six Indian metro cities to find what drives ticket prices.

## Business Questions
- How does price change as departure gets closer?
- Do direct flights cost less than flights with stops?
- Which airlines, cities, routes and departure times are cheapest or priciest?
- Which routes are the busiest?

## Dataset
- Source: Kaggle, "Flight Price Prediction" by shubhambathwal (EaseMyTrip booking data)
- Link: https://www.kaggle.com/datasets/shubhambathwal/flight-price-prediction
- File used: Clean_Dataset.csv (300,153 rows, 11 columns)

## Tools
Microsoft Excel (Excel for the web): Pivot Tables, Pivot Charts, Slicers, Conditional Formatting, AVERAGEIFS and COUNTA formulas

## What I Did
1. Loaded the CSV into Excel and removed the unnamed index column.
2. Converted the data into an Excel Table and checked for duplicates (none found).
3. Built Pivot Tables, 7 charts and a route heatmap.
4. Added a Class slicer (Economy/Business) and KPI cards.
5. Wrote insights and recommendations from the results.

## Key Findings (Economy fares unless stated)
- Booking window: fares average about ₹14,600 one day before departure vs about ₹5,300 at 20 days (about 2.8x), rising sharply in the last two weeks.
- Stops: direct flights average ₹4,013, one stop ₹6,813, two or more stops ₹9,142.
- Business fares average ₹52,540, about 8x Economy (₹6,572).
- Airlines: AirAsia is cheapest (₹4,091). Vistara and Air India make up about 70% of listings.
- Departure time: Morning averages ₹7,119 vs ₹4,785 for Late Night (Late Night has very few flights).
- Cities: Kolkata is the priciest departure city (₹7,459), Hyderabad the cheapest (₹6,236).
- Routes: Delhi–Mumbai is the busiest (15,289 flights). The top 5 routes make up about 24% of listings.

## Recommendations
1. Book at least 3 weeks ahead.
2. Choose direct flights for the lowest fares in this data.
3. Compare departure cities and times, since Morning and Kolkata departures cost the most.

## Limitations
- Data is a snapshot from one booking site, not the whole Indian market.
- Business fares exist only for Vistara and Air India.
- Findings describe this dataset only.
